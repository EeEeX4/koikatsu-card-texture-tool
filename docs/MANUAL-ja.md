# 取扱説明書（1.0）

Koikatsu Coordinate/Chara Texture Optimization Tool —— カード内のテクスチャを再圧縮して、カードのファイルサイズを小さくするツールです。

---

## 1. かんたん導入

1. カード（`.png`）または**フォルダごと**ウィンドウにドロップ（EXE アイコンへのドロップ、「参照…」でも可）
2. 出力先フォルダを選ぶ（既定は `元フォルダ\compressed`）
3. **プリセット**を選ぶ —— 迷ったら **高画質**
4. **▶ 実行** を押す

進行状況と結果は右側の「ログ」に出ます。圧縮後のカードが出力先にでき、**元ファイルは変更されません**。

> ポータブル版：設定はすべて EXE の隣に保存されます（`preset\`、`ui-lang.txt`、`ui-theme.txt`、`ui-layout.json`）。
> レジストリやシステムフォルダには何も書き込みません —— フォルダを消せばアンインストール完了です。

---

## 2. 3 つのモードの使い分け

上部に 3 つのタブがあります。

| タブ | 使う場面 | 特徴 |
|---|---|---|
| **一括圧縮（カード / フォルダ）** | 1 枚でも、フォルダごとでも、大量でも | **テクスチャ種別**ごとに設定（メイン / 法線 / マスク / ハイト…）。もっとも一般的 |
| **衣装カード（部位ごと）** | 1 着の特定の部位だけ綺麗に残したい | **部位**ごとに設定（上衣 / 下衣 / ブラ / アクセサリ…） |
| **キャラカード** | キャラカード（`Koikatu_F_*.png`） | キャラカードは「組・部位」構造。組ごとに一括、または部位ごとに設定 |

**キャラカードと衣装カードは別物です。** 衣装カードに入っているのはテクスチャだけですが、キャラカードにはキャラデータ（顔・体型・性格など）も入っています。キャラカードは 3 ページ目を使ってください。1 ページ目の衣装向け設定を流用しないでください。

---

## 3. 設定項目（1 ページ目）

### テクスチャ種別の表

1 行が 1 種別で、2 つのドロップダウンがあります。

| 列 | 意味 | おすすめ |
|---|---|---|
| **処理方式（形式）** | `自動（安全且つより小さい時のみ JPEG）` = そのテクスチャが JPEG に適していて、かつ小さくなる場合だけ変換。`PNG` / `JPEG` = 強制。`そのまま` = 触らない | **自動**のままで OK |
| **最大辺** | 長辺をこのサイズまで縮小（`4096 / 2048 / 1024 / 512`）。`縮小しない` で解像度そのまま | メイン 2048・法線/マスク 1024 が定番 |
| **スキャン結果** | その種別の枚数・容量と判定 | 「JPEG にして安全か」を教えてくれます |

> 法線・マスク・ハイトは**高解像度を必要としないことが多く**、しかも容量の大部分を占めます。ここを縮めるのが効果的です。

### 一括統一

「一括設定（全種別をまとめて変更）」＋右の「全種別に適用」で、1 セットの値を全種別に書き込みます。あとから種別ごとに微調整もできます。

### 下段のスイッチ

| 項目 | 意味 |
|---|---|
| **JPEG 画質** | 既定 90。下げるほど小さく・粗くなります。JPEG に変換されたテクスチャだけに効きます |
| **シャープ** | 縮小後に軽くシャープをかけ、面積平均で失った細部を取り戻します。0〜200%、数値入力は 500% まで。**実際に縮小された**テクスチャだけに効きます |
| **シャープ方式** | `コントラスト適応`（既定：強いエッジ付近で抑え、ハローが少ない）/ `エッジ感知`（エッジはより鋭く、ハローは出やすい） |
| **グレースケール 2ch** | 3 チャンネルが同じグレースケール画像を 1 チャンネルで保存：**画素は完全に不変**で小さくなります |
| **ディテールマップを保持** | 縮小時に面積平均を使う（きれい）。オフ = 通常の縮小（速い） |
| **カラーも面積平均** | カラーテクスチャにも面積平均＋エッジシャープを適用 |
| **専有テクスチャを保護** | 1 つの部位だけが使うテクスチャは縮小しません（その部位唯一の高解像度元であることが多い）。右の「上限」で緩和先を決めます |
| **アップスケール** | ×2 / ×4 で「最大辺」未満のテクスチャを拡大。**負担が非常に大きい**（実測でカードが約 +36% になることも）。既定では隠れています。通常は不要です |

## 4. プリセット

プリセットは「部位ルール + 個別テクスチャルール + 共通設定」を 1 つの JSON にまとめたもので、**同じ衣装の他のカード**に適用できます。

| 内蔵プリセット | 用途 |
|---|---|
| **最適化のみ** | 可逆再圧縮のみ。**画質はまったく劣化しません**が削減量は控えめ |
| **軽量** | 容量優先、画質は実用十分 |
| **軽量（強）** | 容量最優先 |
| **高画質** | 画質優先（**迷ったらこれ**） |

- **プリセットとして保存…** 調整した設定を JSON に書き出し
- **プリセット読込…** 配布されたファイルを適用
- **プリセットフォルダを開く** 内蔵プリセットの中身を確認
- **選択中のプリセットを既定にする** 次回起動時に自動適用

他のカードを圧縮するとき、まず「同型一致度」を計算します。**しきい値未満ならスキップ**し、ログに一致度を書きます。`force=1` を付けると共通設定だけで強制的に圧縮します。

## 5. コマンドライン

```bat
KoiCardTexTool.exe help                                   :: 引数の一覧

KoiCardTexTool.exe scan     card.png                      :: カード内のテクスチャ一覧
KoiCardTexTool.exe parts    card.png                      :: 部位ごとのテクスチャ一覧

KoiCardTexTool.exe compress in.png out.png 1024           :: 1 枚、最大辺 1024
KoiCardTexTool.exe compress in.png out.png 0              :: 可逆再圧縮のみ（縮小なし）
KoiCardTexTool.exe compress in.png out.png 1024 jpg 90    :: jpg・画質 90
KoiCardTexTool.exe compress in.png out.png 1024 maintex   :: メインだけ圧縮、他はそのまま

KoiCardTexTool.exe batch    D:\cards D:\out 1024 auto 90  :: 一括
KoiCardTexTool.exe batch    D:\cards preset=my.json       :: プリセットで一括
KoiCardTexTool.exe batch    D:\cards preset=my.json force=1   :: 別衣装も共通設定で圧縮

KoiCardTexTool.exe preset   card.png a.json parts=top:auto:512 tex=26:png:256
```

`mode` = `png` / `jpg` / `auto`（既定）/ `maintex`（メインのみ）
`max_size` = 長辺の上限、`0` = 縮小しない

## 6. よくある質問

**圧縮したら大きくなった？**
なりません。実際に小さくなるときだけ置き換えます。ログに「そのまま保持」と出る場合は、その 1 枚は再圧縮が割に合わなかったという意味です。

**法線やマスクも縮小できますか？**
できます。むしろ効果が最大の部分です。容量の半分以上を占めることが多く、1024 でもゲーム内ではほとんど分かりません。

**縮小するとゲーム内で崩れますか？**
解像度を下げると近寄ったときの細部が減りますが、マテリアルの割り当ては変わりません。圧縮前に**必ずバックアップ**してください。

**HDR の環境反射マップは？**
対応しています（Radiance HDR）。他のテクスチャと同じくルールに従いますが、「そのまま」に設定すれば完全に無変更で残せます。

**アップスケールが既定で隠れているのはなぜ？**
実測で、カラー種別をすべて ×2 するとカードが **約 +36%**（カードにより 0%〜+142%）大きくなります。通常はメインだけ拡大すれば十分です。

**ログの「複数部位で共有」とは？**
1 枚のテクスチャを複数の部位が使っている場合があります。変更するには、それらの部位を**すべて**設定に含める必要があります。

**UI の言語・テーマは変えられますか？**
はい。右上の `Language`（中文 / English / 日本語 / 한국어）と `Theme`（ライト / ダーク）。選択は記憶されます。

**出力先は？**
既定は `元フォルダ\compressed\`。ファイル名には既定で `[zip]` が付きます。「同名を上書き」「サブフォルダを含む」も選べます。
