# 사용 설명서 (1.0)

Koikatsu Coordinate/Chara Texture Optimization Tool —— 카드 안의 텍스처를 재압축해 카드 파일 크기를 줄이는 도구입니다.

---

## 1. 빠른 시작

1. 카드(`.png`) 또는 **폴더 전체**를 창에 드롭 (EXE 아이콘에 드롭하거나 「찾아보기…」도 가능)
2. 출력 폴더 선택 (기본값: `원본폴더\compressed`)
3. **프리셋** 선택 —— 잘 모르겠으면 **고화질**
4. **▶ 시작** 클릭

진행 상황과 결과는 오른쪽 「로그」에 표시됩니다. 압축된 카드가 출력 폴더에 생기고 **원본 파일은 변경되지 않습니다**.

> 포터블: 설정은 모두 EXE 옆에 저장됩니다(`preset\`, `ui-lang.txt`, `ui-theme.txt`, `ui-layout.json`).
> 레지스트리나 시스템 폴더에 아무것도 쓰지 않습니다 —— 폴더를 지우면 삭제 완료입니다.

---

## 2. 세 가지 모드 중 무엇을?

상단에 탭이 세 개 있습니다.

| 탭 | 사용 시점 | 특징 |
|---|---|---|
| **일괄 압축 (카드 / 폴더)** | 한 장이든, 폴더든, 여러 장이든 | **텍스처 종류**별 설정(메인 / 노멀 / 마스크 / 하이트…). 가장 일반적 |
| **의상 카드 (부위별)** | 한 벌의 특정 부위만 선명하게 남기고 싶을 때 | **부위**별 설정(상의 / 하의 / 브라 / 액세서리…) |
| **캐릭터 카드** | 캐릭터 카드(`Koikatu_F_*.png`) | 캐릭터 카드는 「그룹·부위」 구조. 그룹 단위 통일 또는 부위별 설정 |

**캐릭터 카드와 의상 카드는 다릅니다.** 의상 카드에는 텍스처만 들어 있지만, 캐릭터 카드에는 캐릭터 데이터(얼굴·체형·성격 등)도 들어 있습니다. 캐릭터 카드는 3페이지를 사용하세요. 1페이지의 의상용 설정을 그대로 쓰지 마세요.

---

## 3. 설정 항목 (1페이지)

### 텍스처 종류 표

한 행이 한 종류이고 드롭다운이 두 개 있습니다.

| 열 | 의미 | 권장 |
|---|---|---|
| **처리 방식(형식)** | `자동(안전하고 더 작을 때만 JPEG)` = 그 텍스처가 JPEG에 적합하고 결과가 더 작을 때만 변환. `PNG`/`JPEG` = 강제. `그대로` = 손대지 않음 | **자동** 그대로 두면 됩니다 |
| **최대 변** | 긴 변을 이 크기까지 축소(`4096 / 2048 / 1024 / 512`). `축소 안 함` = 해상도 유지 | 메인 2048 · 노멀/마스크 1024가 무난 |
| **스캔 결과** | 해당 종류의 장수·용량과 판정 | "JPEG로 바꿔도 안전한지" 알려줍니다 |

> 노멀·마스크·하이트는 **고해상도가 필요 없는 경우가 많고**, 용량의 절반 이상을 차지합니다. 여기를 줄이는 것이 가장 효과적입니다.

### 일괄 통일

「통일 설정(모든 종류 한 번에 변경)」 + 오른쪽 「모든 종류에 적용」으로 한 세트의 값을 모든 종류에 씁니다. 이후 종류별로 미세 조정도 가능합니다.

### 아래쪽 스위치

| 항목 | 의미 |
|---|---|
| **JPEG 품질** | 기본 90. 낮출수록 작아지고 거칠어집니다. JPEG로 변환된 텍스처에만 적용됩니다 |
| **샤프** | 축소 후 샤프를 조금 넣어 면적 평균으로 잃은 디테일을 되찾습니다. 0~200%, 직접 입력은 500%까지. **실제로 축소된** 텍스처에만 적용됩니다 |
| **샤프 방식** | `대비 적응`(기본: 강한 엣지 근처에서 억제, 번짐 적음) / `엣지 감지`(엣지는 더 선명, 번짐은 많음) |
| **그레이스케일 2ch** | 세 채널이 같은 그레이스케일 이미지를 한 채널로 저장: **화소는 완전히 동일**, 용량은 감소 |
| **디테일 맵 보존** | 축소할 때 면적 평균 사용(더 선명). 해제 = 일반 축소(더 빠름) |
| **컬러도 면적 평균** | 컬러 텍스처에도 면적 평균 + 엣지 샤프 적용 |
| **전용 텍스처 보호** | 한 부위만 쓰는 텍스처는 축소하지 않음(그 부위의 유일한 고해상도 원본인 경우가 많음). 오른쪽 「상한」으로 완화 정도를 정합니다 |
| **업스케일** | ×2 / ×4로 「최대 변」보다 작은 텍스처를 확대. **부담이 매우 큽니다**(실측 카드가 약 +36%까지). 기본은 숨김. 보통 필요 없습니다 |

## 4. 프리셋

프리셋은 「부위 규칙 + 개별 텍스처 규칙 + 공통 설정」을 하나의 JSON으로 묶은 것으로, **같은 의상의 다른 카드**에 적용할 수 있습니다.

| 내장 프리셋 | 용도 |
|---|---|
| **최적화만** | 무손실 재압축만. **화질 손실 전혀 없음**, 절감은 적음 |
| **경량** | 용량 우선, 화질은 충분 |
| **경량(강)** | 용량 최우선 |
| **고화질** | 화질 우선 (**고민되면 이것**) |

- **프리셋으로 저장…** 조정한 설정을 JSON으로 내보내기
- **프리셋 읽기…** 공유받은 파일 적용
- **프리셋 폴더 열기** 내장 프리셋 내용 확인
- **선택한 프리셋을 기본으로** 다음 실행 때 자동 적용

다른 카드를 압축할 때 먼저 「동일 의상 일치도」를 계산합니다. **기준값 미만이면 건너뜁니다**(로그에 일치도 표시). `force=1`을 주면 공통 설정만으로 강제 압축합니다.

## 5. 명령줄

```bat
KoiCardTexTool.exe help                                   :: 전체 인수

KoiCardTexTool.exe scan     card.png                      :: 카드 안 텍스처 목록
KoiCardTexTool.exe parts    card.png                      :: 부위별 텍스처 목록

KoiCardTexTool.exe compress in.png out.png 1024           :: 한 장, 최대 변 1024
KoiCardTexTool.exe compress in.png out.png 0              :: 무손실 재압축만 (축소 없음)
KoiCardTexTool.exe compress in.png out.png 1024 jpg 90    :: jpg, 품질 90
KoiCardTexTool.exe compress in.png out.png 1024 maintex   :: 메인만 압축, 나머지는 그대로

KoiCardTexTool.exe batch    D:\cards D:\out 1024 auto 90  :: 일괄
KoiCardTexTool.exe batch    D:\cards preset=my.json       :: 프리셋으로 일괄
KoiCardTexTool.exe batch    D:\cards preset=my.json force=1   :: 다른 의상도 공통 설정으로 압축

KoiCardTexTool.exe preset   card.png a.json parts=top:auto:512 tex=26:png:256
```

`mode` = `png` / `jpg` / `auto`(기본) / `maintex`(메인만)
`max_size` = 긴 변 상한, `0` = 축소 안 함

## 6. 자주 묻는 질문

**압축했더니 더 커졌나요?**
아닙니다. 실제로 더 작아질 때만 교체합니다. 로그에 「그대로 보존」으로 나오면 그 한 장은 재압축이 이득이 없었다는 뜻입니다.

**노멀·마스크도 축소할 수 있나요?**
됩니다. 오히려 효과가 가장 큰 부분입니다. 용량의 절반 이상을 차지하는 경우가 많고 1024여도 게임에서 거의 티가 나지 않습니다.

**축소하면 게임에서 깨지나요?**
해상도를 낮추면 가까이 볼 때의 디테일이 줄 뿐, 머티리얼 연결은 바뀌지 않습니다. 압축 전에 **반드시 백업**하세요.

**HDR 환경 반사 맵은?**
지원합니다(Radiance HDR). 다른 텍스처와 같은 규칙을 따르며, 「그대로」로 두면 완전히 손대지 않습니다.

**업스케일이 기본으로 숨겨진 이유는?**
실측으로 컬러 종류를 모두 ×2 하면 카드가 **약 +36%**(카드별 0%~+142%) 커집니다. 보통 메인만 확대하면 충분합니다.

**로그의 「여러 부위가 공유」는 무슨 뜻인가요?**
한 텍스처를 여러 부위가 쓸 수 있습니다. 바꾸려면 그 부위들을 **모두** 설정에 포함해야 합니다.

**UI 언어·테마를 바꿀 수 있나요?**
네. 오른쪽 위 `Language`(中文 / English / 日本語 / 한국어)와 `Theme`(라이트 / 다크). 선택은 기억됩니다.

**출력 파일은 어디에?**
기본은 `원본폴더\compressed\`. 파일명에 기본으로 `[zip]`이 붙습니다. 「같은 이름 덮어쓰기」「하위 폴더 포함」도 선택할 수 있습니다.
