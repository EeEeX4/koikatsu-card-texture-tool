# 使用手册（1.0）

Koikatsu Coordinate/Chara Texture Optimization Tool —— 把卡片里的贴图重新压缩，让卡片变小。

---

## 1. 快速开始

1. 把卡片（`.png`）或**整个文件夹**拖到窗口里（也可以拖到 EXE 图标上，或点「浏览…」）
2. 选输出目录（默认是 `原目录\compressed`）
3. 「预设」选一个 —— 不确定就选 **质量**
4. 点 **▶ 开始压缩**

进度和结果都写在右边的「日志」里。输出目录里会生成压缩后的卡，**原文件不动**。

> 绿色版：所有配置都写在 EXE 旁边的文件里（`preset\`、`ui-lang.txt`、`ui-theme.txt`、`ui-layout.json`），
> 不写注册表、不写系统目录。删掉整个文件夹就等于卸载。

---

## 2. 三种模式选哪个

窗口上方有三个页签：

| 页签 | 什么时候用 | 特点 |
|---|---|---|
| **批量压缩** | 一次处理一张卡、一个文件夹、甚至一堆卡 | 按**贴图类型**设置（主贴图/法线/掩罩/高度…），最常用 |
| **单服装卡细分压缩** | 想让某一件衣服的某个部位特别清楚 | 按**部位**（上衣/下装/胸罩/饰品…）逐部位设置 |
| **单张人物卡压缩** | 人物卡（`Koikatu_F_*.png`） | 人物卡有「组 · 部位」结构，按组统一或逐部位设置 |

**人物卡和服装卡不是一回事**：服装卡里只有贴图；人物卡里除了贴图还有角色数据（脸、体型、性格等），
所以人物卡要用第 3 页，不要用第 1 页的服装设置去套。

## 3. 选项说明（第 1 页）

### 贴图类型表

每一行是一种贴图类型，两个下拉框：

| 列 | 含义 | 建议 |
|---|---|---|
| **处理方式（格式）** | `Auto（安全且更小才用 JPEG）` = 只有当这张贴图确实适合 JPEG、而且转完更小才转；`PNG` = 强制 PNG；`JPEG` = 强制 JPEG；`原样不动` = 不动 | 保持 **Auto** 最省心 |
| **最大边** | 最长边缩到这个尺寸（`4096 / 2048 / 1024 / 512`），`不缩放` = 分辨率不变 | 主贴图 2048，法线/掩罩 1024 是常用组合 |
| **扫描结果** | 这一类的贴图数量、体积、扫描结论 | 看一眼它会告诉你"这张图转 JPEG 安不安全" |

> 法线、掩罩、高度这类贴图**通常不需要高分辨率**，它们往往是体积大头，缩它们是收益最大的操作。

### 一键统一

「统一设置（一键改所有类型）」+ 右边的「应用到所有类型」：把一套值一次性写给所有类型。
改完仍可逐类微调。

### 下方开关

| 选项 | 含义 |
|---|---|
| **JPEG 质量** | 90 是默认；越低越小、越糊。只影响转成 JPEG 的贴图 |
| **锐化** | 降分辨率之后补一点锐化，把面积平均糊掉的细节找回来。0~200%，数字框可直接输入（上限 500%）。只对**真的缩过**的贴图生效 |
| **锐化算法** | `对比度自适应`（默认，强边附近收敛、白边少）/ `边缘感知`（边缘更锐、更容易出白边） |
| **灰度用 2 通道** | 三个通道相同的灰阶图只存一个通道：**像素完全不变**，体积更小 |
| **细节图保细节** | 降分辨率时用面积平均（更清楚）；不勾 = 普通缩放（更快） |
| **彩色贴图也走面积平均** | 彩色贴图也一起用面积平均 + 边缘锐化，观感更好 |
| **独占贴图保护** | 只被一个部位用到的贴图不跟着降 —— 它往往是那个部位唯一的高清来源。右边的「上限」决定放宽到多少 |
| **放大** | ×2 / ×4 把小于「最大边」的贴图放大。**代价很大**（实测整卡可能 +36%），默认收起，多数人用不上 |

## 4. 预设

预设 =「部位规则 + 单张贴图规则 + 通用设置」打包成一个 JSON 文件，**套用到同款服装的其它卡**上。

| 内置预设 | 适合 |
|---|---|
| **仅优化** | 只做无损再压缩，画质**完全不损失**，体积省得少 |
| **性能** | 体积优先，画质够用 |
| **性能（激进）** | 体积最优先 |
| **质量** | 画质优先（**不确定选这个**） |

- 「保存为预设…」把自己调好的一套导出成 JSON
- 「读取预设…」套用别人给的文件
- 「打开预设目录」看内置预设长什么样
- 「将当前预设设为默认」勾上后，下次启动自动套用

压别的卡时，工具会先算「同款匹配度」：**低于阈值就跳过不压**（日志写明匹配度），
加 `force=1` 则改用通用设置整卡压。

## 5. 命令行

```bat
KoiCardTexTool.exe help                                   :: 完整参数

KoiCardTexTool.exe scan     card.png                      :: 看卡片里有哪些贴图
KoiCardTexTool.exe parts    card.png                      :: 列出每个部位有哪些贴图

KoiCardTexTool.exe compress in.png out.png 1024           :: 压一张，最大边 1024
KoiCardTexTool.exe compress in.png out.png 0              :: 只做无损再压缩（不缩放）
KoiCardTexTool.exe compress in.png out.png 1024 jpg 90    :: 格式 jpg、质量 90
KoiCardTexTool.exe compress in.png out.png 1024 maintex   :: 只压主贴图，其余原样不动

KoiCardTexTool.exe batch    D:\cards D:\out 1024 auto 90  :: 批量
KoiCardTexTool.exe batch    D:\cards preset=my.json       :: 套用预设批量
KoiCardTexTool.exe batch    D:\cards preset=my.json force=1   :: 不同款也压（只用通用设置）

KoiCardTexTool.exe preset   card.png a.json parts=top:auto:512 tex=26:png:256
```

`mode` = `png` / `jpg` / `auto`（默认）/ `maintex`（只压主贴图）
`max_size` = 最长边上限，`0` = 不缩放

## 6. 常见问题

**压完变大了？**
不会。工具只在"确实更小"时才替换那张贴图；日志里写「原样保留」说明这张图重压不划算。

**法线、掩罩能缩吗？**
能，而且通常收益最大。它们往往占体积的一半以上，缩到 1024 在游戏里基本看不出来。

**贴图缩了以后，游戏里会闪/糊吗？**
缩小分辨率主要影响近看时的细节，不会改变材质绑定。压缩前建议**先备份原卡**。

**HDR 环境反射贴图？**
工具支持（Radiance HDR）。默认按规则处理，也可以设成"原样不动"完全不动它。

**为什么"放大"默认是收起的？**
实测把全彩色类都放大 ×2，整卡会 **+36%**（单卡 0%~+142%）。多数人只需要放大主贴图。

**日志里的「同一个部位共用的贴图」是什么意思？**
一张贴图可能被多个部位共用。要改它，必须把这些部位**全部**写进设置里才会动。

**能改界面语言/主题吗？**
能。右上角 `Language`（中文 / English / 日本語 / 한국어）和 `Theme`（浅色 / 深色），选择会记住。

**输出文件在哪？**
默认在 `原目录\compressed\`。文件名默认加后缀 `[zip]`，可选"覆盖同名"或"包含子文件夹结构"。
